## Agent-first boundary

The default `setup` output contains one generic `playwright-cdp` session. A real Chrome CDP endpoint was connected by `doctor`, and both the Codex command and generic stdio MCP JSON were generated successfully. The CDP adapter borrows the existing browser and does not launch another one. Runtime dependencies contain Playwright but no Jet Browser package; Jet adapters are optional compatibility modules only.
