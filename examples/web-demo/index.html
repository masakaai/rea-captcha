browser-use handoff

stop at the gate.
not the whole run.

Keep the browser, cookies, and task context that browser-use already has. rea-captcha separates the interaction from the result: an agent resumes only after a fresh validation signal, while unknown or production challenges remain a bounded handoff.

read the Browser Use CAPTCHA handoff guide →
01 / install the browser-use adapter python -m pip install 'rea-captcha[browser-use] @ https://github.com/masakaai/rea-captcha/releases/download/v0.3.1/rea_captcha-0.3.1-py3-none-any.whl'
02 / attach to the current Agent from rea_captcha import ChallengePlugin; challenge = ChallengePlugin(mode="local", human_handoff=True); await challenge.attach(agent)
03 / analyze without browser control npx rea-captcha@0.3.1 mcp --stateless

The Browser Use adapter borrows the Agent's current BrowserSession; it does not launch another browser. Stateless MCP stays local and does not control a browser. Same-session actions require an explicitly configured, caller-owned session and authorized origin.
